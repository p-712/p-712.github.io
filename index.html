예시: 탐사선이 목표보다 빠른데 AI가 ‘알짜힘과 운동 방향 같음’으로 분류했어요. → 우리는 속력을 줄이기 위해 반대 방향의 알짜힘이 필요하다고 판단해요. 목표 속력에 도달하면 알짜힘이 0이 되도록 해요.

오늘 우리가 할 일 · AI가 운동 그림을 분류하도록 학습시켰다면, 이제 우리 팀이 생각한 과학적 대응 방법을 프로그램으로 만들고 처음 보는 그림으로 검증해 봐요. AI가 알려준 결과가 맞는지 결정하는 사람은 우리예요.
1
CREATE · 프로그램 만들기

Gem에서 HTML 파일 받기

왜 이렇게 할까요? 우리 팀이 선택한 힘의 대응 방법을 실제로 작동하는 프로그램으로 만들기 위해서예요. HTML은 웹브라우저에서 여는 프로그램 파일이에요.

  1. 바로 아래 Gem 열기 버튼을 눌러요. (새 주소를 외울 필요 없어요.)
  2. Teachable Machine에서 복사한 우리 조의 모델 주소를 붙여넣어요.
  3. Gem의 과학 질문에 우리 팀이 생각한 이유를 말해요. 프로그램 이름과 디자인도 선택해요.
  4. 완성된 프로그램에서 코드 다운로드를 눌러 .html 파일을 저장해요.

Gem 대화에는 학생 이름을 쓰지 마세요. 이름은 마지막 Google Forms에만 입력해요.

2
TEST · 처음 보는 그림으로 시험

파일을 열고 AI를 확인해요

왜 시험할까요? AI는 학습할 때 본 그림과 비슷한 모양을 기억해 분류하는 거예요. 처음 보는 그림에서도 제대로 분류하는지 확인해야 믿을 수 있어요.

  1. 크롬북 파일 앱 → 다운로드에서 방금 받은 .html 파일을 찾아요.
  2. 파일을 열어 프로그램이 보이는지 확인해요. 브라우저에서 열리지 않으면 아래 예비 시험 도구를 이용해요.
  3. 바로 아래에서 시험 그림 5개 중 하나를 골라 PNG 저장을 누르세요.
  4. AI가 예측한 운동 유형이 맞는지 확인하고, 프로그램이 알려주는 힘의 대응 방법이 목표에 맞는지 토의해요.
✓ 새로운 그림이 들어갔나요?
✓ AI 분류가 맞았나요?
✓ 대응 방법이 타당한가요?

🧰 파일이 열리지 않나요? 예비 시험 도구

다운로드한 HTML 파일을 이곳에서 골라 새 탭으로 열어 볼 수 있어요. 코드는 서버에 업로드되지 않아요.

아직 파일을 선택하지 않았어요.

  2. 이 그림 PNG 저장을 눌러요.
  3. 우리 프로그램에서 그 PNG를 넣고 AI의 분류와 대응 방법을 확인해요.

3
SUBMIT · 우리 조의 최종 기록

Google Forms에 제출해요

무엇을 제출할까요? 우리가 직접 만든 HTML 프로그램 파일, 처음 보는 그림으로 시험한 결과, 새로 알게 된 점을 제출해요. 파일 안에 프로그램 전체가 들어 있어요.

  1. Google Forms 열기를 눌러요.
  2. 학급·조·학생 1·2 이름, 프로그램 이름을 적어요.
  3. 파일 업로드에서 Gem에서 다운로드한 .html 파일을 첨부해요.
  4. 업로드가 허용되지 않으면, 위의 HTML 파일 선택을 이용해 ZIP 파일 만들기를 눌러 ZIP 파일을 첨부해요.
  5. 시험 결과와 오늘 새로 알게 된 점을 적고 제출을 눌러요.

ZIP 파일도 프로그램을 담은 파일이에요. ZIP을 제출해도 원본 HTML은 안에 그대로 남아 있어요.

제출 완료 여부는 Google Forms에서 확인해요. 이 페이지는 학생 정보를 저장하거나 제출받지 않아요.
* 로컬 HTML에서 외부 AI 모델을 불러올 때 브라우저 보안 설정에 따라 오류가 생길 수 있어요. 예비 시험 도구도 모든 외부 모델의 동작을 보장하지는 않아요. 파일은 Gem에서 직접 만든 신뢰할 수 있는 코드만 열어 주세요.
